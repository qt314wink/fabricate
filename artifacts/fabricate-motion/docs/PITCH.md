# Who to pitch, how to frame

**Author:** Jennipher Troup (`melodicbloom`)  
**Creatives:** `docs/creative/skus/*-hero.jpg` and `*-diagram.jpg`

Do not pitch “a 3D configurator.” Pitch a named crime and a named buyer.

## Outreach sequence

1. CORE + test to the staff engineer (email + 12 min call).
2. If they have modes, add MACHINE.
3. If they already render, add CHROME.
4. One vertical only.
5. TESSELLATE / TOOLPATH only after someone asked for a file or a sim verb.

## Framing lines (use as subject / first slide)

- CORE: The part popped. We made popping illegal.
- MACHINE: Esc always means something.
- CHROME: One writer per property.
- TESSELLATE: A letter. Not the part.
- TOOLPATH: Process from the same NC you can download.
- GESTURE: Mobile subtracts. It does not restyle.
- BRACKET: The plate is still the plate when you add a hole.
- LAMP: Height is not another GLB.
- RING: Size 6 to 8 without a mesh swap.
- STUDIO: One constitution. Three proofs.

## Comparison rules

Never demo against iJewel beauty shots. Demo against *their* current pop.  
Never claim Tylko’s factory. Claim Tylko’s *spine idea* without the plant.  
Never claim OCCT. Point at tandem B8.
